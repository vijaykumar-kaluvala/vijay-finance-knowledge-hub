💻 Excel Practical Lab

Build finance spreadsheets, use formulas, prepare charts and dashboards, and convert raw numbers into useful management reports.

← Back to Student Zone
Excel Lab objective: Students should be able to build a spreadsheet, use formulas, check data quality, create charts and explain the result in a short management report. The workbook uses fictional practice data and is safe to edit.

1. Practical Excel skill pathway

Beginner

Core spreadsheet skills

  • Cell references: relative, absolute and mixed
  • SUM, AVERAGE, MIN, MAX, COUNT
  • IF, SUMIF, COUNTIF, IFERROR
  • Sort, filter, data validation and conditional formatting
Intermediate

Finance analysis tools

  • Ratio calculations and trend analysis
  • XLOOKUP / VLOOKUP and INDEX-MATCH
  • PivotTables and PivotCharts
  • Budget versus actual variance analysis
Advanced

Financial modelling

  • Loan EMI and amortisation schedule
  • NPV, IRR and discounted cash flows
  • Scenario and sensitivity analysis
  • Dashboard with KPIs and management commentary

4. Report writing checklist

  • State the business question and reporting period.
  • Identify the data source and any assumptions.
  • Show formulas and units (₹, ₹ lakh, ₹ crore, %, number of units).
  • Use readable charts with meaningful titles.
  • Explain three key findings and two limitations.
  • End with a practical recommendation.
