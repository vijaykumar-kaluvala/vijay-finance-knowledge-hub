Three-Year Financial Performance Analysis Studio

Learn financial statement data entry manually or use the Excel workbook template. Both methods generate the same three-year comparison.

📘 Step 1 — Understand the data-entry process

For students: Use figures from the same company's published annual reports and keep the unit consistent (for example, all amounts in ₹ lakh or all amounts in ₹ crore). Enter each financial year in its own column. Do not mix standalone and consolidated statements.
Required figures: Revenue, operating profit, net profit, total assets, total debt, shareholders' equity, current assets and current liabilities.
📤 Step 2 — Upload the completed Excel template

Complete the “Financial Data” sheet in the downloaded workbook, save it, then upload the .xlsx file here. Keep the Metric names unchanged so the system can identify each figure.
